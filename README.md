# Arendra — Creative Modern Portfolio

Website portofolio pribadi berbahasa Indonesia dan Inggris, dibuat menggunakan HTML, CSS, dan JavaScript murni.

## Struktur folder

```text
arendra-portfolio/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Menjalankan di VS Code

1. Ekstrak folder `arendra-portfolio`.
2. Buka folder tersebut di Visual Studio Code.
3. (Opsional) Pasang ekstensi **Live Server**.
4. Klik kanan `index.html` → **Open with Live Server**.
5. Tanpa Live Server, kamu juga bisa membuka `index.html` langsung di browser.

## Hal yang perlu kamu ganti sebelum dipublikasikan

Cari dan sesuaikan bagian berikut di `index.html`:

- `emailkamu@example.com` → alamat email aktifmu.
- Tautan `https://github.com/` → URL profil GitHub milikmu.
- Tautan `https://www.linkedin.com/` → URL LinkedIn milikmu.
- Inisial `AR` pada placeholder → boleh diganti dengan foto profil.
- Bagian pendidikan → isi nama kampus, program studi, dan tahun yang benar.
- Tambahkan tautan GitHub/demo pada setiap proyek setelah repositorinya tersedia.
- Pastikan uraian proyek dan pengalaman sesuai dengan yang benar-benar kamu kerjakan.

Foto saat ini berupa placeholder ilustratif, bukan foto pribadi. Bar indikator skill juga hanya elemen visual, bukan hasil pengukuran kemampuan.

## Deploy gratis dengan GitHub Pages

1. Buat akun atau masuk ke [GitHub](https://github.com/).
2. Buat repository baru bernama `arendra-portfolio`.
3. Pilih **Public**, lalu klik **Create repository**.
4. Di halaman repository, pilih **Add file → Upload files**.
5. Unggah `index.html`, `style.css`, `script.js`, dan `README.md` (isi file, bukan folder ZIP).
6. Klik **Commit changes**.
7. Buka **Settings → Pages**.
8. Pada **Build and deployment**, pilih **Deploy from a branch**.
9. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
10. Tunggu proses publikasi selesai. Alamat website biasanya:
   `https://USERNAME.github.io/arendra-portfolio/`

Ganti `USERNAME` dengan username GitHub kamu. Jika nama repository berbeda, bagian URL setelah username juga berbeda.

## Catatan

- Hosting GitHub Pages gratis untuk repository publik.
- Website ini bersifat statis; belum memiliki backend, database, atau formulir kontak yang mengirim data. Tombol email menggunakan aplikasi email melalui `mailto:`.
- Font Google Fonts memerlukan koneksi internet. Jika font tidak termuat, website tetap menggunakan font cadangan.
